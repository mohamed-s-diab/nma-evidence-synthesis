Network Meta-Analysis · Visual Exhibits & Findings

NMA Model Outputs & Figures

Visual gallery presenting the 14 figure exhibits generated by the R pipeline, accompanied by concise summaries of the results.

🔍 Transparency & Dataset Disclosure:
This visual exhibit showcases outputs from an open-source educational R workflow. The data utilized consists of synthetic / simulated benchmark datasets for regimens (Drug A through Drug F) created solely for computational testing and pipeline verification. It does not reflect real-world clinical trials or actual patient records.

Figure 01 Evidence Network Geometry
scripts/designs/fig01_network_geometry.R
📌 Key Takeaway

Summary: Fully connected evidence network of 6 treatment regimens centered on the control anchor `Drug A`, with multi-arm trials and no disconnected nodes or pathways.

Figure 02 Forest Plot vs Reference Backbone (Drug A)
scripts/designs/fig02_forest_plot.R
📌 Key Takeaway

Summary: All active regimens significantly reduced hazard of death versus `Drug A`, with `Drug C` (HR = 0.69) and `Drug F` (HR = 0.72) showing the strongest survival improvements.

Figure 03 Treatment Hierarchy & P-Scores
scripts/designs/fig03_pscore_ranking.R
📌 Key Takeaway

Summary: `Drug C` ranked #1 with the highest P-score of 0.9428, followed by `Drug F` (0.7543), `Drug D` (0.5854), `Drug B` (0.5133), and `Drug E` (0.2009).

Figure 04 Node-Splitting Local Inconsistency Check
scripts/designs/fig04_netsplit_inconsistency.R
📌 Key Takeaway

Summary: Direct and indirect effect estimates showed close statistical alignment across all closed loops (all p > 0.40), confirming network consistency.

Figure 05 Net Heat Inconsistency & Leverage Matrix
scripts/designs/fig05_netheat_plot.R
📌 Key Takeaway

Summary: Matrix diagnostics confirmed neutral background tiles with no localized tension or hotspot driving evidence conflicts across comparisons.

Figure 06 Comparison-Adjusted Funnel Plot
scripts/designs/fig06_funnel_plot.R
📌 Key Takeaway

Summary: Symmetrical distribution around the zero line and a non-significant Egger linear regression test (p = 0.137) indicate absence of small-study effects.

Figure 07 Dual-Model League Table Matrix
scripts/designs/fig07_league_table_matrix.R
📌 Key Takeaway

Summary: Complete pairwise comparative matrix showing that `Drug C` outperforms `Drug A`, `Drug B`, and `Drug E` with clear statistical significance.

Figure 08 Leave-One-Out Sensitivity Analysis
scripts/designs/fig08_leave_one_out_forest.R
📌 Key Takeaway

Summary: Robust findings; `Drug C` retained Rank 1 across 100% of leave-one-out iterations (24/24), demonstrating exceptional stability.

Figure 09 Component NMA Incremental Effects
scripts/designs/fig09_component_effects.R
📌 Key Takeaway

Summary: Component models showed a statistically significant synergistic interaction (p = 0.0004) when adding Component B to the reference backbone.

Figure 10 Probabilistic Rankograms & SUCRA
scripts/designs/fig10_rankograms.R
📌 Key Takeaway

Summary: Rank probability simulations placed `Drug C` with a 98.4% cumulative probability of finishing in the top two ranks (SUCRA = 94.4%).

Figure 11 Bivariate Benefit-Risk Trade-Off Matrix
scripts/designs/fig11_benefit_risk_tradeoff.R
📌 Key Takeaway

Summary: `Drug B` demonstrated favorable efficacy with the best safety profile, while `Drug C` delivered highest efficacy with acceptable moderate toxicity.

Figure 12 Network Meta-Regression Diagnostics
scripts/designs/fig12_metaregression_bubble.R
📌 Key Takeaway

Summary: Meta-regression showed that study publication year, sample size, and setting had no significant confounding or modifying effect (all p > 0.30).

Figure 13 Subgroup Comparative Forest Plot
scripts/designs/fig13_subgroup_forest.R
📌 Key Takeaway

Summary: Subgroup analysis confirmed consistent treatment effects between Global and Asia-Pacific studies (interaction test p = 0.85).

Figure 14 Predefined Clinical Threshold Probabilities
scripts/designs/fig14_mcid_probabilities.R
📌 Key Takeaway

Summary: `Drug C` demonstrated a 99.99% probability of exceeding the predefined threshold (HR ≤ 0.80), followed by `Drug F` (91.92%) and `Drug D` (84.42%).
