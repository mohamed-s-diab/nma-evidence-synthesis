Visual Exhibits & Findings

A clean, publication-grade gallery displaying the 14 visual outputs generated by the R network meta-analysis pipeline, paired with concise empirical takeaways.

Transparency & Dataset Disclosure

This portfolio demonstrates a reproducible statistical workflow in R. The evaluated interventions (Drug A through Drug F) and comparisons use a synthetic / simulated benchmark dataset designed for computational testing and methodological demonstration. It does not contain actual patient data.
